IMPLEMENTATION NOTES

実装するなら、この順番で。

  1. 1 · こうげき短い溜め／突進／ヒットストップ。斬線・集中線・小さなダメージ数字。
  2. 2 · バリア展開の広がり、被弾の波紋、破片、バリア同士の火花と反射軌道。
  3. 3 · まほう弱・強のサイズと溜めを差別化。魔法陣、尾を引く弾、着弾の余波。
  4. 4 · チャージ収束粒子と緑の脈動を追加し、charged / overcharged の段階を見せる。
  5. 5 · 共通の仕上げ画面揺れ・勝ち/まひ/回避とのトーン統一。演出時間と重なりを調整。

実装候補: MoveMotionOverlay.tsx に斬線・火花・衝撃波などの小さな overlay を追加し、globals.css に各 keyframes を定義。組み合わせや順序は battleAnimationPhases.ts、描画とヒット表示は BattlePanel.tsx で調整。

テンポ / 軽さ: 1アクションは約0.5〜1.0秒を目安にし、ターンの読みやすさを優先。アニメーションは主に transform と opacity、少数の要素に限定。低スペック向けに粒子・揺れを控え、prefers-reduced-motion では移動を抑えて結果を残す。

方向性が決まったら、画面の揺れや擬音の量も含めて本実装の仕様を詰めます。
